Sobre o curso

Aprenda React do zero para criar interfaces modernas, reativas e organizadas. Você vai trabalhar com componentes, props, estado, roteamento e consumo de APIs, construindo aplicações web completas e prontas para o mercado.

Ao longo de 160 horas em 6 meses, você aprende a criar componentes reutilizáveis, gerenciar o estado da aplicação, navegar entre páginas com React Router e consumir dados de APIs externas — habilidades essenciais para atuar como desenvolvedor frontend.

React é usado por empresas de todos os setores, incluindo bancos e fintechs, para criar painéis, aplicações de internet banking e plataformas digitais com interfaces modernas e atualizadas em tempo real.

Objetivos de aprendizagem

  • Entender componentes, props e estado em React
  • Criar componentes reutilizáveis e organizados
  • Gerenciar o estado da aplicação com hooks
  • Navegar entre páginas com React Router
  • Consumir dados de APIs externas
  • Construir aplicações web completas e reativas
  • Aplicar React em painéis e plataformas digitais
