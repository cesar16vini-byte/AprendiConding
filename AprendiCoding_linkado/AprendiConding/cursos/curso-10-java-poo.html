Sobre o curso

Aprenda Java com foco em programação orientada a objetos (POO). Você vai trabalhar com classes, objetos, herança, polimorfismo, interfaces e encapsulamento, construindo aplicações organizadas e reutilizáveis para o dia a dia de desenvolvimento de software.

Ao longo de 200 horas em 8 meses, você aprende a pensar em termos de objetos, modelar problemas do mundo real em código Java e criar sistemas com código limpo e fácil de manter — a base para trabalhar com desenvolvimento backend e aplicações corporativas.

Java é amplamente usado no setor financeiro por bancos e seguradoras para sistemas de pagamento, plataformas bancárias e aplicações corporativas que exigem segurança, escalabilidade e estabilidade.

Objetivos de aprendizagem

  • Entender classes, objetos e instâncias em Java
  • Aplicar encapsulamento, herança e polimorfismo
  • Criar interfaces e classes abstratas
  • Trabalhar com exceções e tratamento de erros
  • Organizar código em pacotes e classes reutilizáveis
  • Construir aplicações orientadas a objetos do zero
  • Aplicar POO em cenários reais de sistemas financeiros
