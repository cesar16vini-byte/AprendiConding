Consumindo sua primeira API com JavaScript (fetch + async/await)

Aprenda a buscar dados de uma API pública, tratar a resposta e exibir na página com JavaScript moderno.

O que é uma API?

Uma API (Application Programming Interface) permite que sua aplicação se comunique com outros serviços e troque dados, geralmente no formato JSON.

Usando o fetch

fetch('https://api.exemplo.com/dados')
  .then(resposta => resposta.json())
  .then(dados => console.log(dados));

Com async/await

async function buscarDados() {
  const resposta = await fetch('https://api.exemplo.com/dados');
  const dados = await resposta.json();
  console.log(dados);
}
