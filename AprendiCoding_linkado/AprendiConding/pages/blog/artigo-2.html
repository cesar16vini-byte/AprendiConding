HTML, CSS e JavaScript: como a trindade da web funciona na prática

Entenda o papel de cada tecnologia na construção de uma página e veja um exemplo simples que você pode copiar e testar agora.

HTML — a estrutura

O HTML (HyperText Markup Language) define o conteúdo e a estrutura da página: títulos, parágrafos, imagens, links e formulários.

CSS — a apresentação

O CSS cuida da aparência: cores, fontes, espaçamentos, layout e responsividade para diferentes tamanhos de tela.

JavaScript — a interatividade

O JavaScript adiciona comportamento: botões que funcionam, menus que abrem, dados que carregam sem recarregar a página e muito mais.

Exemplo simples

<button onclick="alert('Olá!')>Clique aqui</button>
