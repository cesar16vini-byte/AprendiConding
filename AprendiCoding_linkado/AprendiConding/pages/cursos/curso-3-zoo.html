Sobre o curso

Aprenda desenvolvimento web construindo um projeto divertido e envolvente: um sistema de catálogo de animais do ZOO. Você vai aprender HTML5, CSS3 e JavaScript básico, consumir APIs públicas e fazer o deploy do seu site, tudo através de um projeto temático que torna o aprendizado mais engajador.

Ao longo de 12 meses, você cria páginas semânticas, estiliza layouts responsivos, adiciona interatividade com JavaScript e publica um site completo no ar. O projeto do ZOO serve como primeiro item do seu portfólio, mostrando que você é capaz de construir uma aplicação web do início ao fim.

Desenvolvedores web são requisitados por empresas de todos os setores, incluindo instituições financeiras que precisam de sites, portais do cliente e sistemas internos baseados na web. Este curso é o primeiro passo nessa direção.

Objetivos de aprendizagem

  • Criar páginas web com HTML5 semântico e acessível
  • Estilizar interfaces com CSS3, incluindo layout responsivo com media queries
  • Programar interatividade com JavaScript básico: variáveis, funções e eventos
  • Manipular o DOM para atualizar páginas sem recarregar
  • Consumir APIs públicas e exibir dados na tela
  • Fazer deploy de sites estáticos e publicá-los na internet

Desenvolvedores web criam sites, portais e sistemas que funcionam no navegador. Eles são requisitados por empresas de todos os tamanhos e setores, desde pequenos comércios até grandes corporações.

No setor financeiro, desenvolvedores web constroem home banking, portais do cliente, páginas de simulação de empréstimo e sistemas de atendimento online. Eles também criam sistemas internos que funcionam no navegador para funcionários de agências e departamentos financeiros, garantindo interfaces rápidas, responsivas e seguras.
