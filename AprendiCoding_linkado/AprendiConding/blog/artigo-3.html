Git e GitHub para iniciantes: controle de versão sem mistério

Commits, branches, pull requests e push: um passo a passo direto para você começar a versionar seus projetos hoje.

O que é o Git?

O Git é um sistema de controle de versão que registra alterações nos seus arquivos ao longo do tempo, permitindo que você volte para versões anteriores quando necessário.

E o GitHub?

O GitHub é uma plataforma de hospedagem de repositórios Git na nuvem. É onde você armazena seus projetos, colabora com outras pessoas e mostra seu portfólio.

Comandos básicos

  • git init — inicia um repositório
  • git add . — prepara arquivos para commit
  • git commit -m "mensagem" — salva as alterações
  • git push — envia para o GitHub
